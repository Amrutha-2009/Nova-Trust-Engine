# NovaTrust

NovaTrust is a web application designed to reduce order cancellations and improve customer trust by analyzing inventory reliability and fulfillment risks.

## Features
- Inventory Trust Score
- Cancellation Risk Analysis
- Smart Recommendations
- Business Impact Dashboard
- Root Cause Detection
- Recovery Plan Generator

## Tech Stack
- HTML
- CSS
- JavaScript

## Purpose
Built as a functional prototype to help e-commerce platforms identify inventory-related trust issues and improve customer retention.
